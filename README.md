# Article Research & SEO Analyzer

Aplikasi Streamlit gratis untuk mengambil artikel publik dari URL dan membuat pemeriksaan dasar SEO on-page.

## Menjalankan lokal
```bash
pip install -r requirements.txt
streamlit run app.py
```

## Deploy publik
1. Buka https://share.streamlit.io/ dan masuk dengan GitHub.
2. Pilih repository `muflihulfata/article-research-seo-analyzer`.
3. Pilih branch `main`, file utama `app.py`, lalu Deploy.
4. Pastikan aplikasi disetel Public agar dapat dibuka pengunjung tanpa login.

Aplikasi tidak memakai API berbayar. Hosting gratis memiliki batas pemakaian dan dapat berubah. Ekstraksi dapat gagal pada situs yang memakai paywall, JavaScript berat, atau proteksi bot.
